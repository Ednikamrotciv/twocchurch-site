=====================================
This zip contains ALL fixes in one place:
- LAST PUBLISHED, NOT LAST UPDATE: this update ships NO words of its own
  (no stored content file inside) — a fresh folder opens on the last
  published words (baked seed), never on anything the update carries. A new
  update refreshes the code only; the words move only when the office
  publishes. The old stored-words file the previous zips carried is gone

  zip into the new folder.

  words outright — with one safety net: the superseded publish is kept on
  the server for about 15 minutes. Tools → Undo the last publish counts
  down while the window is open, works from any signed-in device, restores
  the previous publish whole, then clears it off by itself. After the
  window there is nothing to undo — the old publish is gone off the server.

  never blank (a disk only keeps between-deploy live publishes). Keep
  taking Tools backups either way.
- Everything from 290 and before, unchanged: published words never clear
  unless the office deletes them or a new update lands; slide films autoplay
  silently with their own snapshot first and their own colours behind; tap
  the box → head-on face waits 15s then slides on, every 15s, rotation back

2. Extract THIS zip to a NEW folder (do not extract over the old one).
3. In the new folder: npm install
4. npm run dev → http://localhost:5173/  (admin: /admin)
5. #/admin → Tools → Restore the backup file → Review and publish → Publish.
   Local lifts to 291. Hard-reload desktop + phone width to verify.
   Try the undo: change a line, Publish, then Tools → Undo the last publish
   (it shows the minutes left) — the line must go back. Wait out the window
   (about 15 minutes) and the card must read Nothing to undo.
